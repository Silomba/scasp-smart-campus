# SCASP — Stage 0 Team Scaffold

This is an intentionally **incomplete scaffold** for the BoCS3100 group to implement **Stages 0–11 progressively** with three real GitHub contributors. It contains the same module and build structure as the supplied reference source but **no implemented business logic**. Keep the complete original ZIP privately as an AI-assisted reference and acknowledge it if used.

Open root `pom.xml` with NetBeans/JDK 21; build using `mvn clean verify`; web baseline is a static welcome page deployed on Payara at `/scasp/`. Open `android-client` separately in Android Studio once mobile code is added.

**Start:** Read `docs/TEAM-GITHUB-WORKFLOW.md` and `docs/TEAM-ISSUE-BACKLOG.md`, create the GitHub repo, add two collaborators, create issues, then begin genuine feature work.

This scaffold cannot demo full login, courses, database or Android until contributors implement/merge those issues. Never claim that the scaffold already satisfies the entire assessment.
